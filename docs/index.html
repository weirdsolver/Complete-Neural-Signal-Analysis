No-Code Neural Signal GUI

The GUI/ folder contains the graphical interface for neural signal analysis workflows. It is designed for users with no coding knowledge and accepts a wide range of neural signal file formats, folder structures, table layouts, multichannel recordings, time-series datasets, EEG files, biosignal files, and custom neural signal data structures.

Analysis domains

Core EEG & signals

EEG analysis, neural signal processing, biomedical signal processing, multichannel time-series, phase-space reconstruction, and attractor reconstruction.

Spectral & time-frequency

PSD, Welch method, FFT, Lomb-Scargle, wavelets, STFT, band power, coherence analysis, phase synchronization, and functional connectivity.

Entropy & complexity

Sample entropy, approximate entropy, transfer entropy, multiscale entropy, Kolmogorov-Sinai entropy, entropy rate, and feature extraction.

Chaos theory, Lyapunov exponents, nonlinear coupling, surrogate data, convergent cross mapping, OGY method, and Pyragas control.

Fractal & multifractal

Higuchi fractal dimension, Katz fractal dimension, DFA, MFDFA, Hurst exponent, and wavelet-fractal analysis.

Topology & graphs
