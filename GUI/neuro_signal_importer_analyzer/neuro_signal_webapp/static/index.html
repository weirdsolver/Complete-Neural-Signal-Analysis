    new v0.11.33

    Arnold Tongues / Kuramoto

    Estimates one dominant EEG frequency per channel, converts those into dimensionless Kuramoto natural frequencies, then simulates a phase-forced Kuramoto model over an Arnold tongue amplitude/frequency grid. It now includes oscillator-to-drive locking, collective phase locking, frequency-error diagnostics, contrast heatmaps, and black/cyan plots with visible labels, ticks, legends, and colorbars.

    Arnold tongue and Kuramoto controls
    Ready to run Arnold tongue / Kuramoto analysis.
    Ultra mode is the default. Balanced/full modes increase the Arnold tongue grid density, simulation duration, and contour overlays. The upgraded workflow emphasizes drive-locking and frequency-error diagnostics in addition to mean synchronization.
    new v0.11.33

    Circle Map Arnold Tongues

    Extracts an EEG-derived circular mean phase using the Hilbert transform across all available channels, then computes fixed-point locking probability for the standard circle map over Ω and K. This is the fixed-point-locking workflow from your script, not a full p:q rotation-number Arnold tongue calculation.

    Circle-map controls
    Ready to run circle-map fixed-point-locking analysis.
    Ultra mode is the default. Full mode matches the notebook grid density: 150×150, 60 iterations, and up to 5000 phase samples.
    new v0.11.33

    Circle Map Converged Density

    Uses bandpassed EEG Hilbert phase from all available channels as circle-map initial conditions, iterates final-state probability distributions across K at fixed Ω, and generates the black/cyan density, concentration, resultant-length, and channel-summary plots from your script.

    Converged-density controls
    Ready to run circle-map converged-density analysis.
    Ultra mode is the default. Full mode matches the notebook-style converged-density settings: 300 K values, 50 iterations, 50 bins, and up to 5000 phase samples per channel.
